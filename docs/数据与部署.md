# 数据与部署

## 目录

```
memory-nebula/
├─ web/                  前端（无构建步骤，改完刷新即生效）
│  ├─ index.html         记忆星云主页面
│  ├─ login.html         登录页
│  ├─ settings.html      能力开关
│  ├─ core.html          「数字生命」后台（可选）
│  ├─ graph.json         生成的图（运行期，不入库）
│  └─ vendor/            3d-force-graph / Pico CSS（本地化，离线可用）
├─ memory_view.py        数据 → 图；权限裁剪
├─ viewer_server.py      静态服务 + 接口 + 鉴权
├─ accounts.py           账号与密码
├─ settings_store.py     能力开关读写
├─ core_api.py           「数字生命」接入层
├─ core_life.py          激素/执念/疤痕/梦
├─ demo/make_demo.py     虚构演示数据生成器
├─ tools/check_repo.py   防悬空自检
├─ tests/smoke_test.py   起服务跑一遍接口
├─ docs/                 设计、接口、部署
└─ config.example.json   配置模板
```

## 数据从哪来

| 文件 | 内容 | 必需 |
|---|---|---|
| `data/history.json` | 会话 → 消息列表，key 形如 `private:10002`、`group:555001:10003` | 否 |
| `data/memory.json` | 会话 → 天 → 每日摘要 | 否 |
| `personas/<QQ>/meta.json` | 人格档案元信息，至少 `{"qq": "...", "nick": "..."}` | 否 |
| `config.json` | 管理员、后端、手动圈层 | 否 |
| `bridge.db` | 共用记忆：每轮问答写入 | 否 |
| `brain.db` | 本地伴生：事实、情绪、向量 | 否 |
| `data/vectors-cache.json` | 摘要向量缓存（base64 float32） | 否 |
| `web/graph.json` | 生成结果，页面只读它 | 是（或点「同步」生成） |

所有来源都是「缺了就少一块」，不会让构建失败。最小的可用状态是：一份 `bridge.db`
或 `brain.db`，跑一次 `python memory_view.py`。

### `bridge.db` 的 `memories`

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | INTEGER | 主键 |
| `content` | TEXT | 正文，可能是 `用户：...\n机器人：...` |
| `conversation_key` | TEXT | `private:<QQ>` / `group:<群号>:<QQ>` |
| `created_at` / `updated_at` | INTEGER | **毫秒**时间戳 |
| `subject` | TEXT | 球名（可选） |
| `status` | TEXT | `active` / `faded` / `superseded` |
| `confidence` | REAL | 置信度 |
| `importance` | REAL | 重要度 0~1（缺列时服务端自动补） |
| `superseded_by` | INTEGER | 被哪条替代 |
| `pinned` | INTEGER | 永久标记 |

### `brain.db` 的 `memories`

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | INTEGER | 主键 |
| `speaker_id` | TEXT | 说话人 QQ |
| `kind` | TEXT | `fact` / `preference` / `event` ... |
| `content` | TEXT | 事实正文，常是 `问：...\n答：...\n记：...` |
| `importance` | REAL | 重要度 |
| `confidence` | REAL | 置信度 |
| `strength` | REAL | 记忆强度（会随时间衰减） |
| `created_at` / `updated_at` | INTEGER | **秒**时间戳 |
| `status` | TEXT | `active` / `faded` / `superseded` |
| `source` | TEXT | 来源标记 |
| `superseded_by` | INTEGER | 被哪条替代 |
| `access_count` | INTEGER | 被召回次数 |
| `pinned` | INTEGER | 永久标记（缺列时自动补） |

可选的 `embeddings(memory_id, vec BLOB, dim INTEGER)` 存 float32 向量；
`emotion_state(speaker_id, valence, arousal, affection)` 存情绪，用于星云氛围。

### `config.json`

```json
{
  "admins": ["10001"],
  "backend": "local",
  "known_users": ["10002"],
  "stranger_users": ["10004"]
}
```

- `admins`：管理员 QQ，决定「核心」圈层和核心球；
- `known_users` / `stranger_users`：手动把某人放进熟识/陌生圈（覆盖自动判定）；
- `backend`：仅展示用，`local` 或 `cloud`。

### `settings.json`

由 `settings_store.py` 自动创建，改完按 mtime 热加载，不用重启。常用键：

| 键 | 作用 |
|---|---|
| `recall.enabled` | 是否把记忆塞进提示词 |
| `recall.semantic` | 是否用向量做语义召回 |
| `forget.enabled` | 夜间遗忘结算 |
| `viewer.semantic_edges` | 星云是否算语义边 |
| `viewer.auto_rebuild` | 是否允许定时重建 |
| `embed.provider` | `cloud` / `off` |

## 环境变量

| 变量 | 默认 | 作用 |
|---|---|---|
| `VIEW_DB` | `brain.db` | 本地伴生库路径 |
| `SHARED_DB` | `bridge.db` | 共用记忆库路径 |
| `NEBULA_GRAPH` | `web/graph.json` | 读哪份图 |
| `NEBULA_ACCOUNTS` | `accounts.json` | 账号文件 |
| `NEBULA_ACCOUNTS_KEY` | `accounts.key` | 加密密码副本的密钥 |
| `NEBULA_SESSIONS` | `runtime/sessions.json` | 会话摘要持久化（只存 SHA-256，不含原始 Cookie） |
| `NEBULA_DATA` | `data/` | 数据目录 |
| `VIEWER_READONLY` / `VIEWER_GUEST` | 空 | 等价于 `--readonly` / `--guest` |
| `VIEWER_ACCOUNTS` | 空 | 等价于 `--accounts` |

这些变量对 `memory_view.py` 和 `viewer_server.py` 都生效，方便把代码和数据分开放。

## 跑起来

### 1. 先看演示（不碰真实数据）

```bash
python demo/make_demo.py
python viewer_server.py 8765
```

打开 <http://127.0.0.1:8765/>。演示数据是虚构的四个人、两份库、26 条摘要，
跑完会在根目录生成 `data/`、`personas/`、`bridge.db`、`brain.db`、`config.json`，
这些都写在 `.gitignore` 里，不会进仓库。

### 2. 换成真实数据

1. 删掉演示生成物（或换一个干净目录）；
2. 把 `config.example.json` 复制成 `config.json`，改管理员 QQ；
3. 放入 `bridge.db` / `brain.db`、`data/`、`personas/`；
4. `python memory_view.py` 生成 `web/graph.json`；
5. `python viewer_server.py 8765`。

### 3. 三种服务模式

| 脚本 | 端口 | 绑定 | 用途 |
|---|---|---|---|
| `start-viewer.bat` | 8765 | 127.0.0.1 | 自己用，可写 |
| `start-viewer-readonly.bat` | 8766 | 0.0.0.0 | 只读/访客，正文抹掉 |
| `start-viewer-accounts.bat` | 8767 | 0.0.0.0 | 一人一号，只能看自己 |

手动启动等价于：

```bash
python viewer_server.py 8766 --host 0.0.0.0 --guest
python viewer_server.py 8767 --host 0.0.0.0 --accounts
```

## 重建图

页面上的「同步」会调 `POST /api/rebuild`，立刻重建。也可以定时跑：

```bash
python memory_view.py
```

- Windows：任务计划程序，每 30 分钟执行一次，起始于仓库目录；
- Linux/macOS：`*/30 * * * * cd /path/to/memory-nebula && python3 memory_view.py`。

重建约 200ms（有向量缓存时）。写操作成功后服务端也会自动重建，所以手动定时只是兜底。

## 公网访问

**默认只听 127.0.0.1**。要给不在同一网络的人看，有三条路，按推荐顺序：

### A. 组网工具（最简单）

Tailscale / ZeroTier 这类工具给每台机器一个虚拟内网 IP，让对方直接访问
`http://<虚拟IP>:8767/`。账号模式仍然建议只开给信任的人。

### B. HTTPS 反向代理（推荐给长期使用）

用 Caddy 自动签证书，反代到本机 8767：

```caddyfile
nebula.example.com {
    reverse_proxy 127.0.0.1:8767
}
```

Caddy 会自动带上 `X-Forwarded-Proto: https`，服务端据此给 Cookie 加 `Secure`、给响应加 HSTS。
Nginx 等价配置：

```nginx
location / {
    proxy_pass http://127.0.0.1:8767;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header X-Real-IP $remote_addr;
}
```

### C. 临时隧道

`ssh -R 80:127.0.0.1:8767 nokey@localhost.run` 这类免费隧道可以临时给人看，
地址每次会变，速度一般。**不要把 8767 直接映射到公网**——这是明文 HTTP，
密码会在链路上裸奔。

### 公网前的检查

- [ ] 已经用 `account.bat add` 建了管理员账号，密码是随机强口令；
- [ ] 管理员不是默认的演示 QQ 号；
- [ ] HTTPS 由反代终止，服务端只监听 127.0.0.1；
- [ ] `accounts.json` / `accounts.key` 权限只给当前用户；
- [ ] 关闭「只读/访客」入口，避免拓扑和昵称外泄。

## 备份

需要备份的就四样：

```bash
bridge.db  brain.db  data/  personas/  config.json  accounts.json  accounts.key
```

`web/graph.json` 可以随时重建，不用备份。`accounts.json` 和 `accounts.key` 必须一起备份，
只拷其中一个，密码就解不出来。

## 排错

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面 503「graph.json 还没生成」 | 没跑构建 | `python memory_view.py` |
| 端口被占用 | 已经有一个实例 | 换端口，或先关掉旧窗口 |
| 页面连不上 | 服务窗口关了 / 防火墙 | 看窗口是否还在；局域网模式勾选「专用网络」 |
| 登录一直失败 | 密码错 / 账号文件不在 | `account.bat list`；确认 `accounts.json` 位置 |
| 中文变成乱码 | 用 PowerShell 改过文件 | 用 UTF-8 编辑器重写，跑 `tools/check_repo.py` 前先确认编码 |
| 换了 vendor 的 JS 没生效 | 浏览器缓存 / gzip 旧文件 | 重做 `.gz`，把 `?v=N` 加一 |
| 图很小 / 球在视野外 | 镜头没取景 | 点「回中心」，或刷新（加载会自动 `zoomToFit`） |

## 提交前自检

```bash
python tools/check_repo.py     # 文档引用、接口、导入、脚本、敏感信息
python tests/smoke_test.py     # 真起服务跑一遍
git status                     # 确认没有 db / data / accounts
```

`check_repo.py` 会拦住：文档里提到但不存在的文件、文档里写了但服务端没有的接口、
导入了仓库里没有的模块、`.bat` 调用了不存在的脚本、本机绝对路径、个人 QQ 号、
疑似密钥。它就是为了「防止工具悬空」——文档说得出，仓库里就找得到。
