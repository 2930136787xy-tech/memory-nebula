# 接口说明

所有接口都由 `viewer_server.py` 里的 `Handler` 提供，没有框架、没有依赖。

- 基地址：`http://127.0.0.1:8765`（端口可改，`python viewer_server.py 9000`）
- 请求体：只收 JSON 对象，`Content-Type: application/json`，上限 2MB
- 写请求：除 `/api/login` 外都必须带 `X-Viewer: 1`
- 响应：JSON，`{"ok": true, ...}`；失败是 `{"ok": false, "error": "..."}`
- 账号模式：还需要登录后的 `nebula_sid` Cookie（HttpOnly）

## 模式与权限

| 模式 | 启动参数 | 读 | 写 |
|---|---|---|---|
| 本机 | 无 | 全部 | 全部 |
| 访客 / 只读 | `--guest` / `--readonly` | 完整拓扑，正文抹掉 | 一律 403 |
| 账号 | `--accounts` | 登录后按账号裁剪 | 只能改自己的；管理员全权 |

`GET /api/mode` 返回当前模式，页面据此决定显示哪些按钮：

```json
{"ok": true, "readonly": false, "accounts": false, "guest": false,
 "host": "127.0.0.1", "port": 8765}
```

账号模式下会多一个 `me`：

```json
{"ok": true, "readonly": false, "accounts": true,
 "me": {"qq": "10001", "label": "阿岚", "admin": true}}
```

## 页面

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 星云首页；账号模式未登录会 302 到 `/login` |
| GET | `/login` | 登录页（账号模式） |
| GET | `/logout` | 清 Cookie 并跳回登录页 |
| GET | `/settings.html` | 能力开关页；账号模式仅管理员 |
| GET | `/core.html` | 「数字生命」后台；账号模式仅管理员 |
| GET | `/vendor/*` | 前端库，带 gzip 预压缩和长缓存 |
| GET | `/favicon.ico` | 空响应（204） |

## 读接口

| 方法 | 路径 | 权限 | 返回 |
|---|---|---|---|
| GET | `/api/graph` | 所有模式 | 整张图；访客/普通账号是抹掉正文的版本 |
| GET | `/api/export` | 本机 / 登录 | 两份库里的记忆数组 |
| GET | `/api/settings` | 本机 / 管理员 | 当前能力开关 |
| GET | `/api/accounts` | 管理员 | 账号列表（含可查看的密码） |
| GET | `/api/recall-log?limit=50` | 登录 | 召回日志（管理员看全部） |
| GET | `/api/core?limit=50` | 登录 | 核心候选队列 |
| GET | `/api/conflicts?limit=20` | 登录 | 待处理的新旧事实冲突 |
| GET | `/api/life/state` | 管理员 | 数字生命状态（激素、执念、疤痕、梦） |

`/api/graph` 的返回结构：

```json
{
  "nodes": [{"id": "mem:s:9", "type": "memory", "label": "...", "text": "..."}],
  "links": [{"source": "mem:s:9", "target": "conv:private:10002", "kind": "about"}],
  "meta": {"generated": "2026-10-29 23:26:19", "counts": {"memory": 72},
           "sources": {}, "people": [], "rings": {}}
}
```

节点类型：`core` / `persona` / `conv` / `day` / `msg` / `summary` / `memory`。
关系类型：`core` / `relation` / `owns` / `in` / `active` / `about` / `on` / `superseded` / `semantic`。

## 写接口

### `POST /api/memory`：改一条或一批记忆

单条：

```json
{"store": "s", "id": 9, "op": "edit", "text": "新的正文"}
```

批量（可混库，服务端先全校验再写）：

```json
{"op": "important", "items": [{"store": "s", "id": 9}, {"store": "b", "id": 3}]}
```

也兼容只给 id 的旧写法（服务端自己判断在哪个库）：

```json
{"op": "forget", "ids": [9, 10]}
```

支持的 `op`：

| op | 作用 | 备注 |
|---|---|---|
| `important` / `less` | 重要度 ±0.2 | 共用库同时把强度拉回 1 |
| `pin` / `unpin` | 设为 / 取消永久 | pin 会把状态恢复成 active |
| `forget` / `restore` | 忘掉 / 恢复 | 共用库同步给下游 |
| `delete` | 物理删除 | 二次确认由前端做 |
| `edit` | 改正文 | 共用库同时更新球名；本地库删掉旧向量 |
| `merge` | 合并 | 保留第一条，其余标成 `superseded` |

成功返回：

```json
{"ok": true, "rebuild": {"ok": true, "nodes": 186, "memories": 72, "pinned": 3}}
```

### `POST /api/rebuild`：立刻重建图

无请求体。重建成功返回节点数；5 秒内重复调用返回 429。
账号模式下只有管理员能调（全局图不属于普通账号）。

### `POST /api/settings`：改能力开关

```json
{"viewer": {"semantic_edges": false}}
```

只允许改 `settings_store.KNOWN` 里列出的键；写回 `settings.json`，按 mtime 热加载，不用重启。

### `POST /api/relation`：手动调整关系圈层

```json
{"qq": "10004", "ring": "inner"}
```

`ring` 取值 `core` / `inner` / `outer` / `auto`。仅管理员。

### `POST /api/accounts`：账号管理

仅管理员，且不能删除自己、不能改自己的角色。

| action | 参数 | 说明 |
|---|---|---|
| `add` | `qq`, 可选 `password`, `admin` | 不传密码则随机生成 12 位 |
| `passwd` | `qq`, 可选 `password` | 改密后旧会话立即失效 |
| `remove` | `qq` | 删除账号 |
| `role` | `qq`, `admin` | 设为 / 取消管理员 |

### `POST /api/core`、`POST /api/conflicts`

处理核心候选（`approve` / `reject`）和事实冲突（`keep_old` / `keep_new`）。
普通账号只能处理自己的队列项，管理员不限。

### `POST /api/life/action`

「数字生命」后台的操作（激素、执念、疤痕等）。仅管理员。

## 错误码

| 码 | 含义 |
|---|---|
| 400 | 请求体不是 JSON 对象 / 参数不合法 |
| 401 | 未登录或会话过期（账号模式） |
| 403 | 只读模式写入 / 权限不够 / 缺少 `X-Viewer` |
| 404 | 接口或记忆 id 不存在 |
| 413 | 请求体超过 2MB |
| 415 | `Content-Type` 不是 `application/json` |
| 429 | 登录试错过多 / 同步太频繁 |
| 503 | `graph.json` 还没生成 |

## 调用示例

```bash
# 读模式
curl -s http://127.0.0.1:8765/api/mode

# 把一条共用记忆设为永久
curl -s -X POST http://127.0.0.1:8765/api/memory \
  -H "Content-Type: application/json" -H "X-Viewer: 1" \
  -d '{"store":"s","id":9,"op":"pin"}'

# 重建
curl -s -X POST http://127.0.0.1:8765/api/rebuild -H "X-Viewer: 1"
```

账号模式先用 `/api/login` 拿 Cookie：

```bash
curl -s -c cookie.txt -X POST http://127.0.0.1:8767/api/login \
  -H "Content-Type: application/json" \
  -d '{"qq":"10001","password":"..."}'
curl -s -b cookie.txt http://127.0.0.1:8767/api/graph
```
