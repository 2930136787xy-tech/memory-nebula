## 技术社区（V2EX / 掘金 / 少数派）

**标题**：我给 QQ 机器人做了个三维记忆星云，顺手解决了「记忆黑箱」

**正文**：

> 机器人跑了一段时间，记忆库涨到几百条。召回能用，但作为主人，我看不见它到底
> 记住了什么、哪些快忘了、有没有记错。
>
> 所以做了这个页面：把两份记忆库（实时问答写入的共用记忆、夜间提炼的本地事实）、
> 私聊消息、日摘要和人格档案，合成一张三维力导向图。六个类型、九种关系、
> 三层关系圈（核心/熟识/陌生），颜色分类、大小表重要度、灰度表遗忘强度。
>
> 几个实现上的点：
>
> - **两份库，一种 id**：`mem:s:9` / `mem:b:9`，前端不用知道有几个库，服务端按前缀路由；
> - **语义边不炸**：两两余弦是 O(n²)，先用 1/8 维粗排，再算全量，记忆只比最近 120 条；
> - **首屏 1.7MB → 0.45MB**：动态 gzip + vendor 预压缩 + 长缓存；
> - **权限分三层**：本机全权、访客只看拓扑；一人一号时每个人都能登录，**查看并操作自己的那一份**，别人的内容抹掉；管理员才看全部、管账号；
> - **零依赖**：Python 标准库起 HTTP 服务，前端两个本地库，离线可用。
>
> 仓库里带了一套虚构演示数据和自检脚本，克隆后 `python demo/make_demo.py` +
> `python viewer_server.py 8765` 就能看效果。没有真实聊天记录、账号或密钥。

## 长文导语（公众号 / 知乎）

> 我们习惯说「它记得我」，但很少有人能回答：它到底记得什么？
>
> 记忆在数据库里是一行行文本：时间、重要度、强度、向量。对人来说，这些字段
> 不构成「记得」。直到把它们放进空间——谁和谁相连、哪些在中心、哪些正在变灰——
> 「它记得我」才第一次有了形状。
>
> 这篇文章讲我怎么把一份聊天机器人的记忆做成三维星云：为什么选力导向图、
> 每个视觉元素对应哪个字段、两份记忆库怎么合并、权限怎么裁、以及踩过的六个坑。
